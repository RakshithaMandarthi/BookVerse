# BookVerse — Static Frontend Website

Open `index.html` in a browser to run the website.

Included pages:
- Home
- Discover Books
- Book Details
- Book Discovery Quiz
- My Library
- Authors
- Categories
- Community
- Login

Features:
- Light-blue premium visual design
- Responsive desktop/tablet/mobile layout
- Animated hover buttons/cards
- Mobile menu
- Light/dark mode
- Book cover images
- Search and category filters
- Book details
- Quiz with recommendations
- LocalStorage demo library/favorites/theme
- Demo login
- Community content
- Newsletter interaction

This is a STATIC frontend. No real database, server authentication, payments, or backend API are included. The structure is ready for a backend to be connected later.
